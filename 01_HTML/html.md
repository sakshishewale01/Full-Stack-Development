# HTML Introduction

## 📖 What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages. It tells the browser what content should be displayed, such as headings, paragraphs, images, links, tables, forms, and more.

HTML is **not a programming language** because it does not contain programming logic like loops, conditions, or functions. Instead, it is a markup language that uses tags to describe the structure of a webpage.

---

## 🌍 Full Form

**HTML = HyperText Markup Language**

### HyperText
HyperText refers to text that contains links to other web pages or resources. These links allow users to navigate between pages.

### Markup
Markup means using tags to define and organize the structure of content.

### Language
HTML has a predefined set of rules and tags that browsers understand.

---

## 🎯 Why Do We Use HTML?

HTML is used to:

- Create web pages
- Display text, images, audio, and videos
- Create forms for user input
- Build navigation menus
- Organize webpage content
- Connect web pages using hyperlinks

Without HTML, a web page cannot exist.

---

## 🚀 Features of HTML

- Easy to learn
- Platform independent
- Free and open standard
- Supported by all web browsers
- Can be combined with CSS and JavaScript
- Provides semantic elements for better accessibility and SEO(Search Engine Optimization)

---

## ⚙️ How HTML Works

1. Developer writes HTML code.
2. The file is saved with a `.html` extension.
3. The browser reads the HTML file.
4. The browser interprets the tags.
5. The webpage is displayed on the screen.
